- 公共 API 通过 `__init__.py` 显式 re-export，使用 `from . import X as X` 形式保留原始名称，便于外部按模块名引用。
- 类级状态通过 `ClassVar` 或类属性（如 `SignedParams.Data`、`_session`）维护，所有方法均为 `@classmethod`，避免实例化。
- 配置文件读取统一走 `ConfigManage.get_config(ConfigType, names)`，利用 Pydantic `TypeAdapter.validate_python` 进行强类型校验。
- 字符串到列表的转换一律使用 `ast.literal_eval` 而非 `eval`，并在失败时记录错误日志后抛出异常或返回空值。
- 异步 I/O 操作统一通过 `aiohttp.ClientSession` 复用连接，并在 `close()` 中显式关闭 session。
