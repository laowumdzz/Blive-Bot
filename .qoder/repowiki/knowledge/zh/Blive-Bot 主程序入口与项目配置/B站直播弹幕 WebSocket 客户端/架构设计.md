模块以 `BLiveClient`（`__init__.py`）为唯一对外入口，内部按职责拆分为：
- 协议层：`enum.py` 定义 `ProtoVer`、`Operation`、`AuthReplyCode`；`config.py` 通过 Pydantic `BaseModel` 声明配置项并提供 B站 API URL。
- 连接管理层：`BLiveClient` 使用 `aiohttp.ClientSession` 获取房间信息与签名参数，通过 `websockets` 建立 WSS 连接，按 B站二进制头部（`HEADER_STRUCT = struct.Struct(">I2H2I")`）收发封包，并维护 `_Heartbeat_Task` 每 30s 发送心跳。
- 消息分发层：`handler.Handler` 通过 `_CMD_MODEL_DICT` 将 cmd 映射到 `models.MessageInterface` 子类，并由 `append_func` 装饰器注册回调函数，实现命令→模型→处理器的解耦。
- 数据模型层：`models.py` 中所有消息类型均继承 `MessageInterface` 并实现 `from_command(raw_msg)` 工厂方法，运行时通过 `_all_subclasses` 自动枚举生成 `MsgType`。
- 异常与常量：`exception.AuthError` 用于认证失败传播。
依赖方向单向向外：`__init__` → `config/enum/handler/models/exception`，各子模块之间无循环引用。
